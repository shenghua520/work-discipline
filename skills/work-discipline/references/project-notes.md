# 项目笔记｜特定后端的私有经验

> 触发场景：只在操作**这套特定后台**时读；换项目不要套用这里的字段语义。
> 这里放的是「某个系统的坑」，不是通用纪律。通用规则在 `execution-layer.md`。

## 配置读取

- 读配置只用 GET；**禁止空 body POST**——该后端会把它当成重置指令，直接清掉配置。

## 批量作业

- 异步任务的响应形如 `result:true` + `taskId`；**必须回读落账**，禁止把"已受理"当成"已生效"。

## 全量复核

- 全量扫描时把字段分两类：**STATIC 变即失败**、**VOLATILE 只报告**。判定"不多不少"用具体 ID 存在性，不用总数（总数会漂）。

## 使用方式

把这三条当作"该项目适配层"：执行层的七步法是骨架，这里是具体参数。换到别的后台时只保留骨架，这里的参数作废——不要把它们误当成跨项目通则。
